# Viewer の開発と保守

[English](../../../skills/q-flow/references/viewer-development.md) · [简体中文](../zh-CN/viewer-development.md) · [Русский](../ru/viewer-development.md) · [Português](../pt/viewer-development.md) · [日本語](viewer-development.md) · [Deutsch](../de/viewer-development.md) · [Español](../es/viewer-development.md)

モジュールはビルド時に合成します。ソース変更後にビルドすると、生成器が全機能を単独 HTML に埋め込みます。実行時のプラグイン取得やホットロードはありません。通常の生成物は引き続き `index.html` と `graph.json` のみです。

## 変更箇所

パスは `assets/viewer/src/` からの相対パスです。

| 目的 | 入口 | 担当 |
| --- | --- | --- |
| 図の種類を追加 | `diagrams/<type>.js`、`diagrams/registry.js` | 名前、順序、許可する種類、固有検証、描画、輪郭、関係ポリシー |
| テーマ・文字サイズ・行高 | `visual-style.js`、`radix-colors.js` | ページと出力で共用する Radix 色階、テーマ変数、意味色、中心判定、寸法 |
| ノード形状・内部配置 | 対応する `diagrams/<type>.js`、共通カードは `diagrams/card.js` | ページと SVG/PNG の両方 |
| 共通 SVG 文字組み・図形 | `diagrams/drawing.js` | `svgStyles()`、エスケープ、共通図形。ページ内スコープと出力で再利用 |
| ツールバー・詳細・レスポンシブ外枠 | `ViewerShell.jsx`、`styles.css` | ページ外枠。ノード内容を別の HTML/CSS で二重実装しない |
| キャンバス発光 | `effects.css`、`main.jsx` で `styles.css` の後に読み込む | 役割・選択・流れの発光、暗色ビネット。パレット変数のみ。ファイル単位で除去でき、透明度低減・高コントラスト時は無効 |
| 選択・検索 | `features/useSelection.js`、`search.js` | 共通選択、フィードバック、キー操作、解除。検索順位は独立テスト可能 |
| 有向辺の動き | `features/useViewerController.js`、`DiagramCanvas.jsx` | 方向だけを表し、専用スイッチと動きを減らす設定で制御 |
| 読み取り用凡例 | `ViewerShell.jsx`、`styles.css`、内容は `legend.js` と `visual-style.js` | 実在する分類と線種から浮動凡例を作る。元の記号、`nodeAppearance`、中心優先を維持 |
| パネル・フォーカス | `features/usePanels.js` | モバイル排他、表示、フォーカス復帰。図切替時もパネル設定を維持 |
| キャンバス全画面 | `features/useFullscreen.js`、`features/useSelection.js` | ネイティブ全画面、失敗通知、フォーカス復帰。全画面内選択で外部インスペクターを開かず、Escape は全画面を先に終了 |
| ドラッグ・表示範囲・ロック・間隔 | `features/useGraphLayout.js`、`layout-nudge.js` | 現在位置と配置操作。D3 は範囲を制限した微調整 |
| 表示状態 | `features/usePresentation.js` | 選択・検索をノードと辺へ反映し、状態の所有者を増やさない |
| ダウンロード | `features/download.js`、`export-svg.js` | 現在座標から静的 SVG を作り、その SVG を PNG 化 |
| 経路・配置検証 | `edge-routing.js`、`text-layout.js` | ページ・出力・検証で経路、折返し、計測を共用 |

`main.jsx` は読み込み、図切替、テーマ、図ごとの編集下書きを所有します。`features/useViewerController.js` が機能と保存/リセットを調整し、`ViewerShell.jsx` が UI を結びます。既存モジュールを先に拡張し、独立した状態とライフサイクルにだけ新しい Hook を作ります。

## 図の種類を追加する

1. `diagrams/` に定義をデフォルトエクスポートするモジュールを追加します。
2. `diagrams/registry.js` から読み込み `DIAGRAMS` に登録します。登録順がコレクションのメニュー順です。単図には種類メニューがありません。
3. `graph-schema.md`、`visual-contract.md`、SKILL の作図手順を更新します。登録だけならデータ構造の変更は不要な場合があります。
4. テンプレートをビルドし、例を生成して固有ノード、関係、ブラウザー操作を検証します。

既存規則と図形を再利用します。アーキテクチャの規則をすべて継承するカード表示は `{ ...architecture, id: 'new-view', label: 'New view' }` と登録だけで十分です。独立した種類の典型例：

```js
export default {
  id: 'new-view', label: 'New view',
  nodeKinds: ['component'], groupKinds: [], edgeKinds: ['call'],
  outline, // (node, x, y) => [[SVG タグ名, 幾何属性], ...]
  render,  // (node, x, y, fill, stroke, palette) => SVG 文字列
};
```

`render` は `paint(outline(node, x, y), { fill, stroke })` で本体を、`text` / `centeredTitle` で文字を描きます。モジュールコードは信頼済みですが、グラフデータは未信頼です。共通エスケープを通さずに入力を SVG タグ・属性・文字へ連結しないでください。

必要な場合だけフックを追加します。

- `validateNode`、`validateEdge`：共通検証後の制約。渡された `requireString`、`validateStringArray` などを再利用。検証ごとに順序番号の集合を新規作成します。
- `edgeLabel`、`undirected`、`dashedKinds`、`markers`：関係ラベル、方向、証拠線種以外の固有破線、既存 UML マーカー。
- `cardLayout`、`compartments`、`sequence`、`cardinalities`、`endpointStub`、`selectionHeight`：カード検証、中心区画、ライフライン、ER 端点、選択高さの既存規則。

矩形カードは既存規則を使えます。異なる経路・接続点・UML 記号には共通経路/描画の拡張が必要で、登録から未知の幾何形状は推定できません。新しい意味分類は `visual-style.js` に名前と `nodeAppearance` を追加します。HTML と SVG に `radix-colors.js` の Radix MIT 表記を残します。

## 共通描画の制約

`DiagramCanvas.jsx` と `export-svg.js` は共に `node-svg.js` の `renderNode()` を呼びます。ページは SVG を React Flow ノードへ挿入し、出力は同じ描画器へキャンバスオフセットを渡します。`SelectionOutline.jsx` は `renderSelection()` と種類の `outline` を再利用し、線・不透明度・影だけを変更します。

位置、内容、一時的な操作状態を分離します。ドラッグは現在座標を変え、選択は座標も形状も変えません。出力は現在のグラフとテーマだけを受け取り、選択やアニメーションを受け取りません。境界、React Flow マーカーへの適応、ページ操作部品にはホスト固有描画が残ります。内容共有はページ DOM と出力 SVG の同一性を意味しません。

## ビルドと回帰確認

スキルのディレクトリで既存依存関係とブラウザーツールを使います。

```bash
npm --prefix assets/viewer run build
node --test scripts/*.test.mjs
node scripts/generate-viewer.mjs /tmp/graph.json /tmp/new-viewer
node scripts/browser-interactions.mjs /tmp/new-viewer /tmp/new-viewer-check
```

左下の全画面ボタンはキャンバスをネイティブ全画面にし、浮動パネルと上部バーは外に残します。寸法変更後は選択や配置を変えず一度だけ全体を収め、終了時は表示範囲を維持します。照準アイコンは全体表示、四隅アイコンは全画面切替です。既存 HTML は再生成が必要です。非対応なら操作不能を示し、要求失敗はキャンバスのステータス領域へ通知します。

全画面確認には実ブラウザー API を使います。`QA_HEADED=1` は全画面、Escape、フォーカスを確認するウィンドウを開きます。

```bash
QA_HEADED=1 QA_ONLY_EXTRAS=1 QA_EXTRAS=fullscreen,fullscreen-errors \
node scripts/browser-interactions.mjs /tmp/new-viewer /tmp/fullscreen-check
```

ブラウザースクリプトは入力された全種類を 3 サイズ、明暗テーマ、各操作で検査します。全マトリクスには 9 種類のコレクションを渡します。`QA_FIXTURE_DIR` で特殊形状の検体を追加できます。隣接ソースモジュールが必要で、スクリプトだけのコピーでは動きません。

詳細はユーザー選択に従います。`useSelection` が選択を所有し、`useViewerController` が `inspectedNode` を導出、`ViewerShell` のクイックビューとインスペクターが利用します。自動再生、段階的読解、フロー実行制御はありません。凡例は左上の浮動ボタン、`.inspector-facts` は詳細の末尾です。`DiagramCanvas` の `has-flow` と `styles.css` が流動中の静的レイヤーの対比を制御し、選択で動く破線の隙間を埋めてはいけません。

```bash
QA_ONLY_EXTRAS=1 QA_EXTRAS=flow-contrast,inspector-sync \
node scripts/browser-interactions.mjs /tmp/new-viewer /tmp/new-viewer-sync-check
```

`diagram-modules.test.mjs` は一時コピーに 10 番目のテスト種類を追加し、そのコピーのモジュールとレジストリだけを変えて検証・ビルド・生成します。製品は 9 種類のままです。`MODULE_TEST_OUTPUT=/tmp/new-module-check` でコピーを残し、内部の `skills/q-flow/scripts/browser-interactions.mjs` で `page/` を検査します。コピーは実際のビルド依存を検証するためリポジトリ階層とルートの第三者表記を保持します。出力先は未存在でなければなりません。

変更後は `assets/viewer-dist/index.html` を再ビルドします。インストール後は実キャッシュを確認し、新規セッションでインストール済み版から確認用出力を生成します。既存 HTML は旧コードを内包するため再生成します。

| スキルのディレクトリと呼出し | `create-interactive-codegraph` / `$create-interactive-codegraph` | `q-flow` / `$q-flow` |

パッケージには新しいスキル入口だけを残し、旧別名は設けません。対象は引き続き 9 種類のソフトウェア図です。MapSprig / QMindFlow の改名は対象外です。

リポジトリルートから新パスを使います。

```bash
node skills/q-flow/scripts/validate-graph.mjs /tmp/graph.json
node skills/q-flow/scripts/generate-viewer.mjs /tmp/graph.json docs/qgraphflow/example-architecture
```

既定ディレクトリはスキルの納品規約で、生成器には明示的な出力先が必要です。`docs/codegraph-flow/` などユーザー指定の旧ディレクトリは利用可能で、上書きには引き続き `--force` が必要です。旧 `graph.json` の書換えは不要で、タイトル・出典・ノード・証拠内の旧名は保持します。旧 HTML はオフラインで使えますが旧ブランドを表示するため、元 JSON から再生成します。

`CodeGraph`、`codegraph`、`@colbymchenry/codegraph`、`.codegraph/` は外部分析ツールの名前で不変です。内部の `__CODEGRAPH_FLOW_DATA__`、`codegraph-*` SVG ID、テスト一時ディレクトリ接頭辞も保持します。

## Viewer の視覚・操作契約

保守または操作監査時に読む節です。作図には [visual-contract.md](visual-contract.md) を使います。

### 共通表示

- キャンバス中心の React Flow 外枠を使います。全面キャンバスは 52px のマテリアルツールバーの下まで広がります。バーにはナビ切替、集合の図メニュー、題名/副題、検索結果ポップオーバー、出力/リセット/配置ロック/間隔/外観の `···` メニュー、インスペクター切替を置きます。ボード見出し、フッター、ブランド枠はなく、製品名は文書タイトルだけです。ナビとインスペクターは各端から入る浮動パネルで、全幅で初期は閉じます。ノードクリックは横にクイックビュー（種類、名前、責務、出典、最大 4 タグ、詳細ボタン）を出し、インスペクターは開きません。図を最も強く見せます。
- 外観は既定で `prefers-color-scheme` に追随しライブ更新します。`···` にシステム/ライト/ダークの分割選択を置き、手動設定を両方向で優先。テーマ変更は表示範囲、検索、選択、ロック、パネルを維持します。
- 共通パレットは Radix Colors（MIT）：冷中性色面に Slate、中心/操作に Iris、データに Cyan、判断/失敗に Orange。配布ソース、HTML、SVG に著作権/許諾を残し、実行時 CDN やコンポーネントライブラリは不要です。
- 真の業務中心を既存 `business` または大文字小文字を区別しない `core`/`business` タグで示します。Iris 3 の塗り、Iris 8 の枠、Iris 12 の文字。ER/クラスはヘッダーだけで、メンバー行は中性です。中心はデータ/警告より優先。初期/終了状態は黒丸/二重丸を保ち、`core` 種類や色フィールドを追加しません。
- ページ、ノード、MiniMap、詳細の色点、凡例、出力は `visual-style.js` を共用。通常カードは Slate 2、ライトキャンバスは Slate 1（`#fcfcfd`、ほぼ白）でダークと同じ第 1 段階です。ダークには対応する暗色階を使います。
- 外枠の色は `styles.css` が `color-mix` でパレットから導出：4 段階の `--label`、`--label-2/3/4`、区切り `--sep`、3 段階の `--fill`、`--fill-2/3`、材質 `--material-thick`、`--material`、`--material-thin`。暗色では材質ベースと影だけを上書きします。外枠文字は 11 / 12 / 13 / 15 / 20 px、SVG は `TYPOGRAPHY` / `--font-*`。全操作に `:active` と共通 `:focus-visible`、パネルには .5px 線と一層の影、`1px solid` はキャンバス記号だけ。`prefers-reduced-motion` に加え、`prefers-reduced-transparency` は不透明 `--panel`・ぼかしなし、`prefers-contrast: more` は区切り/補助文字をラベル色、浮層を 1px 枠にします。

| 用途 | Radix 色階 |
| --- | --- |
| ページ / 通常面 | Slate 1 / Slate 2 |
| 主 / 補助文字 | Slate 12 / Slate 11 |
| 中心の塗り / 枠 / 文字 | Iris 3 / Iris 8 / Iris 12 |
| 操作 / 有向の動き | Iris 11 |
| データの塗り / 枠 / 強調 | Cyan 3 / Cyan 8 / Cyan 11 |
| 警告の塗り / 枠 / 強調 | Orange 3 / Orange 8 / Orange 11 |
| 薄い枠 / 通常辺 | Slate 6 / Slate 9 |

- ライトで `module` がなければ役割色、あればカード全面・輪郭・上帯をモジュール色にします。確認済み中国語 EC 例の対応は 渠道 `#6b7280`、结算 `#5753d7`、价格 `#8b5cf6`、库存 `#0f8f83`、风控 `#c26a17`、支付 `#2474d2`、订单 `#348052`、履约 `#b14b7d`。色は目立たせても、文字・形・多重度・線種・ステレオタイプの代用にはせず、選択中も塗りを維持します。
- 凡例は実在する分類と線種だけから作り、中心優先、意味表示、現在テーマを描画と揃えます。
- 左上の凡例ボタンで開くポップオーバーに、有向関係があれば流動スイッチを置きます。各ラベル前に元の形・テーマ色・実破線を保持した記号を置き、通常のインライン文字として折り返します。ナビ展開時は右へ避け、パン/ズームで位置や文字寸法を変えません。Escape または外側クリックで閉じます。
- 有向関係は既定で始点から終点へ淡い短線を 1 本動かし、無向は静止。下の証拠の実線/破線を保ち、選択でも動かします。流動スイッチは環境の短線だけを止め、動き低減は環境動作全体を止めます。
- ホバー/選択は輪郭と影だけで、形を拡大したり意味色を置換しません。選択ノードと直接辺に一度だけ共通の 760ms 反発をかけ、以後静的強調。線幅、不透明度、影だけを動かします。
- `effects.css` は `styles.css` 後の画面専用層。暗色では `.node-surface` にモジュール色（なければ役割色）の `filter: drop-shadow`、ホバー/選択発光、広い光輪（ノード 14px・.5、直接辺 14px・.3、動く短線の基準対比 ≥60%）、太い `.edge-flow`、上端から 10% 強調色の放射ビネットを加えます。ライトは同モジュールの柔らかい影と平面背景。パレット token のみを使い、カード `box-shadow` は使いません（ライフラインは `boxShadow === 'none'`）。出力には影響せず、`prefers-reduced-transparency: reduce` / `prefers-contrast: more` で層全体を無効化し、filter は `none`、光輪/流動は `styles.css`、ビネットは除去します。
- 動き低減では関係/選択アニメーションを止め、表示移動を即時にします。
- SVG/PNG は現在テーマ、記法、文字階層、共通直交経路を使用し、一時的な選択/検索強調を除外。文字と記号は形の内側に保ち、SVG 説明に全文を残します。

### 操作

- 単図にメニューはありません。集合は正規順の `role=menu` と `menuitemradio` を使い、現在項目のチェックと各関係数を表示。切替は各図の保存済み文字/位置を保ち、検索と旧選択を消し、全体表示と初期中心選択を適用します。
- 自動再生、ステップ、読解ツアー、現在/完了ステップはありません。旧 `playback` は無視し、辺の動きは実行順序を示しません。
- 初期は明示された最初の中心ノードと直接辺を静的に選択し、脈動させません。切替も同じで、中心がなければ未選択です。
- 選択はクイックビューを開き、直接の入出辺を一緒に強調します。自己ループは一度、先への探索や無関係辺の減光はしません。現在経路を使い、矢印を追加/拡大せず、証拠破線、ER 多重度、UML 記号を保ちます。
- 輪郭はカード、菱形、平行四辺形、楕円、状態円と一致。シーケンスはヘッダー/人物だけでライフライン全体ではありません。760ms 後は静的。別ノードは集合全体を置換し、同じノードは一度再生します。
- クリック/ドラッグ開始は選択とクイックビュー、一覧/検索と Enter/Space はインスペクターを開きます。辺は動き続け、操作ごとにフィードバック/位置決めを一度だけ実行。ドラッグで再中心化やフォーカス移動をしません。
- キャンバスクリック、詳細を閉じる、Escape で解除。検索は不一致ノードを薄くし、構造は不変です。
- インスペクターはユーザーが変更/解除するまで全事実、フィールド、null 可否、属性、メソッド、出典、タグを保持し、自動進行やフォーカス奪取をしません。
- 選択中も有向の動きを識別可能にし、静的な同色不透明線で隙間を埋めません。最初の辺や `animationPlayState` だけでなく全直接有向辺を検証。動き低減と独立スイッチを優先します。
- 検索は大小文字と前後空白を無視。完全名、名前前方一致、部分一致、副題/タグ、事実/フィールド/属性/メソッドの順で、同順位は元順、並べ替え後に 8 件を取ります。
- 配置は既定ロック、明示操作でドラッグを許可し、出力は現在位置を使います。
- 間隔整理は解錠後の限定 D3 微調整です。選択時はそのノードと 1 ホップ隣接、未選択は全体。矩形間 65px を目標に元位置近くに留め、包含ノードは最小境界内、シーケンス参加者は水平方向だけ。新しいトポロジーや全自動配置ではありません。
- ロック中も整理項目は灰色 `aria-disabled="true"` でマウス/キーを受け、ステータスに解錠要求を伝えます。ロック名は一行、スイッチは全幅でメニュー内 32×20px。解法実行/自動解錠はしません。解錠後は局所/全体と移動数、変更不要か、残る問題数と手動調整を通知。エラーと警告の両方を数え、移動ゼロでも未解決を報告します。
- 156px の移動上限内で境界に望ましいヘッダー/余白が入らなければ元位置を保持し、問題を報告。無関係ノードは小数も含め座標を完全維持。操作ごとに同文でも状態と 4.5s タイマーを更新します。
- 整理は証拠、経路ヒント、グループ、選択、表示範囲、パネル、テーマを変更しません。リセットは元 `graph.json` の位置と読解ビューを戻し、検索/選択/旧状態を消し、流動を既定へ。テーマ、パネル表示、ロックは保ち、既存ステータスに完了を通知します。
- パン、ズーム、全体表示、リセット、SVG/PNG 保存を維持します。
- Graph JSON 保存は全図の現在文字/位置を元の単図/集合形式で保存し、メタデータ、出典、構造フィールドを保持。対応時はネイティブ保存、それ以外はダウンロード。取消/失敗でも編集を保持。リセットは現在図だけで次回保存へ反映。再読込は埋込データなので保存 JSON から再生成します。回帰は往復切替、リセット分離、JSON 保存と再生成を含みます。
- キー選択とパネル閉鎖は構造を保ち、Backspace/Delete はノードを削除しません。
- 開く/リセット/切替は全体表示。パン/ズーム/MiniMap で詳細へ。範囲は出力と共通で、ノード、群、外側経路、ラベル、ER 端記号を含みます。一覧選択/適合はドラッグや整理後の現在位置、リセットは元位置です。
- 全適合（初期、リセット、切替、全体表示、全画面開始）は UI を控除：上部 52px+12px、下部操作行、左右はパネル開時 304px+24px、閉時 24px。`useGraphLayout.js` の `readingPadding()` は `data-nav-open` / `data-drawer-open` を読みます。padding は `px` 文字列で、裸数値は比率です。
- ナビ/詳細スイッチ、クイックビュー詳細で開いたパネルが選択ノードを覆う場合だけ、境界から 12px 離れる最小パンを行い、ズームは維持。非遮蔽時と ≤700px は動かしません。`useReveal.js` はこの 3 操作から明示呼出し、effect ではありません。一覧/検索は従来どおり中心化します。
- プログラム移動（適合/位置指定/露出）は 320–420ms の `cubic-bezier(.32,.72,0,1)`。パネルは臨界減衰 spring（`visualDuration .36`、`bounce 0`）。動き低減は両方 0 時間、移動を描かず終点に表示します。
- ズームは全ノードを一体で拡縮し、副題、フィールド、属性、メソッド、ステレオタイプを隠しません。全画面も同じ。中央文字は矩形内で折返し、菱形/楕円/丸角/斜辺では幅を狭めます。大文字識別子/幅広ラテン文字を見積もり、境界タイトルはフラグメント記号を避けます。`text-bounds` は全種類、長いフィールド/メンバー、境界名、大文字辺、3 段階ズームを検査し、非空原文の opacity 0 で失敗します。
- クイックビューは右→左→下→上から、画布内で他ノードを覆わない最初の位置を選びます。入る側がすべて隣接ノードを覆う場合は実高さで最小重なりを選択。`is-flipped / is-below / is-above` の `transform-origin` でノード側から展開します。
- 長文カードは高さ内で折返し/スクロールし、閉じる/詳細をキーで操作可能に。全画面の詳細操作は終了後に既存インスペクターを開いてフォーカス。終了拒否ならカードを保持しエラー通知します。
- ナビ開時に凡例/ズームは左 328px、詳細開時に MiniMap は右 328px（`.workspace.nav-open / .drawer-open`）。≤700px は動かしません。
- SVG/PNG は現在表示範囲だけでなく全図を含みます。

### レスポンシブ配置

- 全幅で両パネル初期閉鎖、幅 304px、上はツールバー下+12px、下は窓下−12px。背景幕なしで隣のキャンバスをパン可能にします。Escape はポップオーバー、フォーカスを持つパネル（バーへフォーカス復帰）、選択の順。中間幅で証拠入口を削除しません。
- ≤700px は窓幅−24px、一方を開けば他方を閉じ、MiniMap を隠します。検索結果は詳細を開きナビを閉じます。
- モバイル操作を到達可能にし、パネル横に見えるキャンバスを残し、390px で横溢れを防ぎます。インスペクターは全文と縦スクロールを維持します。

### 証拠表示

- 詳細は識別情報、フィールド、属性、メソッド、出典、タグを先に、その後に同じ選択ノードの事実を独立した末尾節へ。出典ありは証拠事実、なしはノード説明。事実や選択がなければ省略し、詳細と一緒にスクロールします。
- 直接のソース、設定、スキーマ、テスト、文書は実線。ただし戻り、依存、実装など記法が破線を要求する場合は従います。
- フレームワーク挙動と推論は破線で、流動中も区別を保持します。
- 詳細は「証拠」と表記し、全出典をソースコードと呼びません。
- 事実、副題、フィールド、メソッド、出典シンボル、タグの長い語は折り返し、全文を保ち縦スクロールだけにします。
