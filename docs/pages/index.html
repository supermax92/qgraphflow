QGraphFlow

Interactive software diagrams from real code: nine diagram types, a source for every relationship, automatic layout, editing in the page, and no network requests from the page itself.

从真实代码生成可交互的软件图：九类图、每条关系都标出处、自动布局、能在页面里编辑，页面本身不发任何网络请求。
