# Fictional library examples

These examples were independently authored for public layout and interaction testing. They do not describe a real organization, repository, implementation status or compatibility guarantee.
The capabilities example contains a library service, ten library functions, a reader terminal and a staff console. The service provides catalog access; the loans function supports reader operations.
The engineering example contains a fictional library service with query and import modules. Its query detail has an HTTP endpoint, a lending use case and a catalog port, alongside unit and contract checks.
Badges describe this fixture only. All relationships are conceptual document statements. The separate source-project fixture is backed only by its checked-in synthetic POM files.
